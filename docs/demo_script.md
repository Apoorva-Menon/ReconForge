# Demo script

1. Seed labeled transaction pairs and active policy v1.
2. Run initial reconciliation and show baseline metrics.
3. Inject a recurring small fee mismatch and start investigation.
4. Show governed diagnosis, retrieved memory, bounded candidate, and deterministic backtest.
5. Persist a checkpoint, pause for human approval, approve, resume, promote, and replay open cases.
6. Show updated metrics and episode memory; demonstrate a later evidence doorbell resuming a waiting case.
